# Site content

Open this folder as an Obsidian vault. Edit the Markdown pages here, then run `python3 build.py` from the repository root to regenerate the HTML served by GitHub Pages. Local generation requires Pandoc.

The root `.html` files and `blog/` pages are generated output; edit the Markdown sources instead.

Use `#`, `##`, and `###` for the page title and section headings. Blog posts belong in `posts/`; copy `_template.md` to a filename like `2026-09-22-a-short-title.md`. Each post appears on the Blog page and gets its own HTML page. Put figures in `media/` and use either `![caption](media/file.png)` or Obsidian `![[file.png]]`; Obsidian `[[about]]` links become page links.
